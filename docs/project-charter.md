# CampusFix --- Project Charter

## 1. Project Name

**CampusFix**

## 2. Project Overview

CampusFix is a simple issue-tracking website designed to make it easier
for students to report maintenance problems on campus.

Students can report facility problems such as broken air conditioners,
lights, fans, toilets, and Wi-Fi. University staff can use the system to
organize, prioritize, and manage maintenance requests.

## 3. Problem Statement

Students have difficulty reporting campus problems because they may not
know who to contact or how to report them.

CampusFix aims to provide students with a simple way to report
maintenance problems so that university staff can find and fix them more
quickly.

## 4. Project Goal

The goal of CampusFix is to provide an easy-to-understand website that
helps students report campus facility problems and helps university
staff manage those problems.

## 5. Target Users

-   Students
-   University staff
-   Lecturers

## 6. Main Features

### Student Reporting

-   Select the room where a problem occurs.
-   Select the type of issue.
-   Submit a maintenance report.

### Staff Management

-   View maintenance requests.
-   Organize and prioritize maintenance requests.
-   Update the status of a request from **Reported** to **Fixed**.

### AI Chatbot

-   Guide users through reporting.
-   Help users check report status.
-   Help users navigate the platform.

## 7. Project Scope

### In Scope

-   Reporting campus maintenance problems.
-   Identifying the room and issue type.
-   Managing maintenance requests.
-   Updating request status.
-   Providing an AI chatbot to guide users.

### Out of Scope

The provided project material does not define additional features
outside the functions described above. Any additional scope should be
agreed upon by the project group.

## 8. Expected Outcome

CampusFix should give students a simple way to report campus problems
and help university staff know what needs to be fixed.

providing a simple reporting system.
