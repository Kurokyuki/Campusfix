# CampusFix

CampusFix is a campus maintenance issue-tracking website.

## About the Project

CampusFix allows students to report campus facility problems such as:

- Broken air conditioners
- Broken lights
- Broken fans
- Toilet problems
- Wi-Fi problems

University staff can view, organize, prioritize, and update maintenance requests.

## Main Features

- Student maintenance reporting
- Room and issue selection
- Maintenance request management
- Report status tracking
- AI chatbot assistance
